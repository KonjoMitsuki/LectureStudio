## 解決した環境問題

- Codexホームが外側の実行サンドボックスで読み取り専用となり初期化に失敗。承認された通常ホスト実行で実測。モデル側は `read-only` とツール無効化を維持。
- Remotion依存のインストールを重ねて失敗。インストールを一本化し、専用キャッシュとnpm 10.9.4で再構築。
- 依存監査でKaTeXの低重大度問題を検出。0.19.0へ更新。
- 大容量VOICEVOX配布は公式のバイト範囲を検証して再開。7-Zipによる全アーカイブの検査成功。
- 同時に大容量展開を行った初回のChromium接続が25秒でタイムアウト。展開完了後の再実行でフレーム出力成功。
- Remotionが標準でChromiumの保護無効化フラグを渡すため、`scripts/chromium_sandbox.py` でサンドボックス、Web security、サイト分離等を無効化する引数を除去する。

## Phase 1

Phase 0の実MP4検証後にMVPを実装し、Webから開始した6分44秒の動画の生成・再試行・再生・保存まで成功。

通常Chromiumの動画レンダリングでは、Remotionの共有メモリ描画で序盤の進捗が停止した。
公式オプション `disableSharedMemoryCapture: true` で標準フレーム撮影へ切り替え、全2206フレームのMP4生成に成功。
音声合計71.488秒、各シーンに15フレームの余裕を加えた表示合計73.533秒。

- 単体・API結合テスト: 通常のWSLホストで31件成功（`data/unit-results-host.log`）。PDF実体・容量・設定・Origin・Host・不正ID、二重生成拒否、生成中削除拒否、Range、ダウンロード、失敗後の台本再利用、破損した台本キャッシュの再生成、二重ワーカー拒否、再起動時復旧、Chromiumの保護フラグを検証。
- フロントエンド: TypeScriptとViteの本番ビルド成功。RemotionのTypeScriptチェック成功。
- 依存監査: フロントエンドは導入時の監査で公開脆弱性0件。
- 実ブラウザのホーム表示: 成功（`data/mvp-home.png`）。
- 実サービスE2E: 成功。12シーン・1,990文字の台本を実Codexで生成。実VOICEVOXで398.39秒のナレーションを合成。7種類の図解を使用した404.567秒（6分44秒）のMP4を生成。
- 図解部品: フローチャート、状態遷移、ブロック図、ネットワーク、タイムライン、比較表、数式、キーワードの8種類すべてで実Remotionフレーム出力成功（`data/diagram-gallery/result.json`）。
- 台本内容: 線形探索の比較5回、二分探索の比較3回、整列の前提、最悪計算量O(n)/O(log n)、補足例を本文と照合。ユーザー固有の他の講義資料の品質保証とは区別する。
- 制限環境のPython APIテストはスレッド間通知で待機した。ホストで同じテストが7.08秒で成功したため、アプリの保護設定は変更しない。

## 最終のブラウザ・動画検証

- Playwrightの実Chromium（sandbox有効）で2件成功（`data/e2e-final.log`、`data/e2e-result.json`）。
- 生成動画の再生と時間の進行、チャプターへシーク、元PDFページ画像、MP4保存を確認。
- 390px幅の画面で横方向にはみ出さず、保存操作可能。JavaScriptの実行エラー0件。
- 保存したMP4のサイズ10,900,219バイト。FFprobeで映像12137フレーム、1920×1080、30/1fps、H.264 High、yuv420p、AAC LCを確認。
- 映像404.566667秒、音声404.567000秒。長さの差は約0.000333秒。
- FFmpegの音量解析でも音声データの存在を確認（`data/audio-check.log`）。
- 失敗した描画ジョブからブラウザの再試行ボタンを押し、同じ台本・音声を再利用して完了。ジョブ履歴に失敗と完了を保持。
- 不正な拡張子/実体の拒否と、破損PDFの解析失敗・再試行表示も実ブラウザで確認。

最初の長時間ブラウザテストでは接続リセットが発生した。状態取得に接続リセットの再試行を加え、同一のアップロード済み講義で検証を継続した。
通常Chromiumの全フレーム描画を、既知のアニメーション・強調切り替え・フェードの区間だけの描画へ最適化した。
FFmpegで元のフレーム時刻を復元して30fpsの静止区間を補間し、シーンごとの実WAVを必要な長さまで余白追加して結合する。
小規模MP4で再検証後、長尺を再試行した。描画枚数は12137枚から2724枚へ減らした。

最終テストは生成済みの同一講義IDを使う継続検証（`resumed=true`）。初回の実ブラウザからのアップロード・実AI・実音声のログと、継続後の再試行・MP4・再生保存の証拠を組み合わせて全工程を確認している。
動画を作らず固定JSONで成功扱いするテストではない。

## 未検証・対象外

- ユーザーが普段使う別の大学講義PDF、多数ページの実用教材全般。
- 15〜30分の長尺、全話者、全読み上げ速度・解説レベルの組み合わせ。
- OCRによる画像PDF解析、図表の画像認識、台本編集、音声辞書。
- Windows側の実ブラウザでの手動操作。ブラウザ検証はWSLの実Chromiumで実施。
- 検証用PDFはプロジェクト内で作成した日本語教材で、外部大学のPDFではない。
