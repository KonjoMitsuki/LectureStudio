# 内容から設計する絵コンテ

新規生成は、図解テンプレートの選択をやめ、説明したい関係・変化から構図を設計する。AIは各シーンの `storyboard.intent` に説明の意図を記録し、文字・矩形・楕円・線・矢印を配置する。タイトルも任意の文字要素であり、同じ位置への表示は強制しない。字幕と出典は独立した領域に残す。

`prompts/analyze.txt` は、分割内の項目全体の理解の流れを考えてから絵コンテを作るよう指示する。新しいAI出力は全シーンの絵コンテを検証し、欠落時は修正・既存の分割再試行に進む。旧形式に自動で戻さない。保存済み講義を読む汎用バリデーターでは旧形式を引き続き受け入れる。生成バージョンを6に変更したため、更新前の台本を新規生成のキャッシュとして再利用しない。

## データ

`renderer="remotion"`, `visual=null`, `animation=null` とし、`storyboard` を設定する。構図名の列挙はない。

```json
{
  "intent": "不要な候補を消し、残った値に注目する",
  "elements": [
    {"id": "candidate", "kind": "rect", "x": 120, "y": 200,
     "width": 180, "height": 120, "text": "14", "font_size": 56,
     "align": "center", "tone": "fg", "fill": "card", "opacity": 1}
  ],
  "beats": [
    {"cue": "残りに注目します", "transition_seconds": 0.6,
     "changes": [{"target": "candidate", "x": 640, "y": 160,
                  "width": 280, "height": 200, "font_size": 88}]}
  ]
}
```

この例はローカル保存形式で、省略値に既定値を使う。Codexへ渡すスキーマは全フィールドを必須にし、変更しない `changes` のフィールドは `null` を使用する。

- キャンバスは1696×668、映像上の左112・上112から始まり、下端780。字幕は上816から始まる。
- 最大24要素、32 beat。要素の順番が描画の重なり順。外部URL・HTML・SVGコード・任意スクリプトは扱わない。文字はReactの通常のテキストノードとして描画する。
- `kind` は `text/rect/ellipse/line/arrow`。線は `(x,y)` から `(x+width,y+height)` へ描画するため、幅・高さに負数を使える。
- `tone` は `fg/muted/accent/warm/cool`、`fill` は `none/card/accent/warm/cool`。3つの既存スタイルは色調に適用する。
- 文字は28〜120px。改行は明示し、文字幅・高さを概算検証する。自動縮小はしない。図形との重なりや楕円内の文字、色のコントラストの最終確認は人によるプレビューが必要。
- `cue` はナレーション原文を出現順に指定する。WAV実時間と文字位置からフレームを推定する近似同期。思考時間には新しい変化を追加せず、問題の最終状態を保持する。
- 位置・幅・高さ・文字サイズ・不透明度は0〜2秒で補間。文字・色・塗りはcue時点で切り替わる。移動中に次の操作が来たら、その時点の表示状態から次へ動く。未指定の属性は前の目的値を維持する。
- 要素IDはシーン内で有効。次のシーンへ図を継続する場合は前の最終状態と次の初期状態を同じ値にする。絵コンテのシーン境界には自動フェードを入れない。シーンをまたぐIDの自動継承はない。

## 描画と検証

Pydantic・JSON Schemaで型・要素数・参照・有限数・領域・文字サイズ・各変更後の状態を検証する。ナレーション中のcue順序も検証する。既存の資料参照、網羅性、クイズと正答の対、音声による実時間計測は維持する。単調さや意味的な正確さを自動保証するものではない。

フレームキャッシュは各beatの開始から終了までの全フレームを保存する。静止区間は従来通り省略する。レンダラーはフレーム0から状態を評価するため、途中へのシークや中断再開でも同じ絵になる。新しい描画コードは既存のキャッシュキー計算に含まれる。

```bash
npm run test:unit
video/node_modules/.bin/tsc -p video/tsconfig.json
# 実Chromium・FFmpegで19.5秒の検証MP4を生成。AI・VOICEVOXへの接続不要。
LECTURE_CHROMIUM_PATH=/absolute/path/to/chromium .venv/bin/python scripts/verify_storyboard.py
```

検証用音声は人工音で、実ナレーションではない。問い・候補の消去と拡大・候補数の比較という3つの構図を描画し、字幕・映像・音声・長さ・解像度・コーデックを検査する。出力は `work/storyboard-smoke/`。新しい形式での実Codexと実VOICEVOXを通した講義全体の生成品質は、別途実教材で評価する必要がある。
